# Tabletop Fest — website starter

A fictional, anonymised event website inspired by the general structure of large tabletop gaming conventions. It does not use official branding, logos, photography, contact details or event information.

## Files
- `index.html` — page structure and sample content
- `styles.css` — styling, layout and responsive breakpoints
- `script.js` — mobile navigation and demo newsletter response

## Run in VS Code
1. Unzip the project folder.
2. Open VS Code and choose **File → Open Folder**.
3. Open `index.html`.
4. For the easiest preview, install the **Live Server** extension, then right-click `index.html` and choose **Open with Live Server**. Alternatively, open `index.html` directly in a browser.

## Customise
- Search for `TABLETOP FEST` in `index.html` to change the fictional brand.
- Replace the example dates, venue, ticket price and opening times with your own details.
- The coloured blocks labelled `IMAGE PLACEHOLDER` are intentionally CSS-generated placeholders. To use your own images later, place them in an `images` folder and change each `.placeholder-image` block in HTML/CSS.
- The newsletter form is front-end demo behaviour only; it does not send or save email addresses. Connect a form service or backend before collecting real subscriptions.

## Notes
This is a static front-end prototype. Ticket sales, event databases, user accounts, and real email subscriptions need a backend or third-party service.
